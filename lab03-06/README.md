## О проекте

**CodeSlicer** — приложение для анализа программного кода и визуализации связей между его компонентами.

Система помогает разобраться в структуре проекта, найти зависимости между файлами и функциями, а также понять, на какие части программы могут повлиять изменения.

При выполнении лабораторных работ в качестве аналога рассматривалась **Kodik IDE** — среда разработки с поддержкой AI-инструментов. В CodeSlicer также предусмотрены возможности интеграции с редакторами кода и AI-агентами.

## Основные возможности

- Анализ структуры программного проекта.
- Построение интерактивного графа зависимостей.
- Поиск связей между файлами, функциями и модулями.
- Оценка влияния изменений в коде.
- Работа через веб-интерфейс и локальный API.
- Интеграция с Visual Studio Code и AI-инструментами.

## Лабораторные работы

В рамках лабораторных работ №3–6 рассматриваются следующие технологии и принципы разработки:

**ЛР №3 — Клиентская часть приложения**

Создание интерфейса с использованием HTML, CSS и JavaScript, работа с элементами страницы и отображением данных.

**ЛР №4 — Серверная часть**

Организация работы локального HTTP-сервера на Python, обработка запросов и передача данных в формате JSON.

**ЛР №5 — Взаимодействие клиента и сервера**

Обмен данными между веб-интерфейсом и API, отправка запросов и обработка ответов.

**ЛР №6 — Асинхронная работа с данными**

Использование Fetch API и асинхронных JavaScript-функций для получения информации от сервера и обновления интерфейса.

Все четыре работы рассматриваются на примере одного приложения CodeSlicer.

## Используемые технологии

- **HTML, CSS, JavaScript** — веб-интерфейс.
- **Python** — серверная часть и анализ исходного кода.
- **HTTP API, JSON, Fetch API** — обмен данными.
- **TypeScript** — расширение Visual Studio Code.
- **Git и GitHub** — хранение и управление исходным кодом.

## Как запустить

Для запуска необходим **Python 3.10 или новее**.

Откройте PowerShell в папке `lab03-06` и выполните:

**1. Создание виртуального окружения**

```powershell
py -3 -m venv .venv
```

**2. Установка зависимостей**

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
```

**3. Запуск приложения**

```powershell
.\.venv\Scripts\python.exe -m impact_engine.local_api --host 127.0.0.1 --port 8001 --default-project .
```

После запуска откройте в браузере:

**http://127.0.0.1:8001/**

Для остановки сервера нажмите `Ctrl+C` в терминале.
