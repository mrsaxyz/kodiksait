# Лабораторные работы по дисциплине «Разработка интернет-приложений»

**Сигорский Александр, ИБМ3-54Б.**

Исходники и отчёты ЛР №3–6:

- [`lab03-06/`](lab03-06/) — отдельный учебный Node.js/JavaScript-модуль по мотивам CodeSlicer: карточки (ЛР3), REST API + Postman (ЛР4), XHR + CORS (ЛР5), Fetch/Promise/async-await и bundle (ЛР6).

> Учебный модуль **не содержит ядро настоящего CodeSlicer** и **не анализирует исходный код**. Production-система CodeSlicer реализована отдельно: https://github.com/artemnoor/CodeSlicer.

### Запуск ЛР3–6

```powershell
cd lab03-06
npm run build
npm test
npm start
```

Откройте `http://127.0.0.1:8001/` (ЛР6) или `http://127.0.0.1:8001/lab03/` (ЛР3). Подробная инструкция, включая демонстрацию ЛР5 с CORS и коллекцию Postman, — в [`lab03-06/README.md`](lab03-06/README.md).

**Важно для преподавателя:** общая папка предназначена для удобства проверки, а методичка предполагает отдельные Git-ветки каждой ЛР; их необходимо сформировать дополнительно. Тема «услуги и заявки» должна соответствовать выданному варианту.
