## Как запустить и использовать проект

В репозитории представлены лабораторные работы по дисциплине **«Разработка интернет-приложений»**.

Проект разделён на две части:

- **ЛР №1–2 — Kodik Calculator:** калькулятор на HTML, CSS и JavaScript.
- **ЛР №3–6 — CodeSlicer Learning Hub:** учебное веб-приложение для управления проектами с использованием JavaScript, Node.js, REST API, XMLHttpRequest и Fetch API.

### 1. Скачивание проекта

Для работы с проектом необходимо установить [Git](https://git-scm.com/downloads) и [Node.js](https://nodejs.org/) версии 18 или новее.

Откройте PowerShell и выполните:

```powershell
git clone https://github.com/mrsaxyz/kodiksait.git
cd kodiksait
```

Если репозиторий уже скачан, достаточно открыть его папку.

Проверить установленную версию Node.js можно командами:

```powershell
node -v
npm -v
```

### 2. Лабораторные работы №1–2 — калькулятор Kodik

Откройте папку `lab01-02` и запустите файл `index.html` двойным нажатием. Он откроется в браузере.

Калькулятор позволяет:

- выполнять сложение, вычитание, умножение и деление;
- переводить байты в биты;
- работать с историей вычислений;
- вводить числа с клавиатуры;
- удалять символы и очищать результат.

Калькулятор работает без установки дополнительных библиотек и без запуска сервера.

**Отчёт:** `lab01-02/report.pdf`.

### 3. Лабораторные работы №3–6 — CodeSlicer Learning Hub

Для этих лабораторных используется отдельное учебное приложение.

Откройте PowerShell в корне репозитория и выполните:

```powershell
cd lab03-06
npm run build
npm test
npm start
```

Назначение команд:

- `npm run build` — собирает JavaScript-файлы ЛР6 в `bundle.js`.
- `npm test` — запускает автоматические тесты REST API.
- `npm start` — запускает локальный Node.js-сервер.

После запуска сервер доступен по адресу `http://127.0.0.1:8001`.

Оставьте окно PowerShell открытым, пока используете приложение.

### 4. ЛР №3 — карточки проектов

Откройте в браузере:

http://127.0.0.1:8001/lab03/

На странице можно:

1. Просматривать карточки проектов.
2. Искать проекты по названию или языку программирования.
3. Нажимать «Подробнее» для открытия детальной информации.
4. Дублировать первый проект с помощью кнопки добавления.
5. Удалять отдельные карточки.
6. Возвращаться к списку с помощью кнопки «Домой».

Данные в этой лабораторной хранятся в JavaScript-массиве непосредственно в браузере. После обновления страницы список возвращается к исходному состоянию.

### 5. ЛР №4 — REST API на Node.js

При запущенном сервере откройте:

http://127.0.0.1:8001/api/projects

Браузер покажет JSON-массив проектов.

API поддерживает следующие операции:

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/projects` | Получение списка |
| GET | `/api/projects/1` | Получение одного проекта |
| POST | `/api/projects` | Создание проекта |
| PUT | `/api/projects/1` | Изменение проекта |
| DELETE | `/api/projects/1` | Удаление проекта |

Для проверки операций удобно использовать [Postman](https://www.postman.com/).

В папке `lab03-06/postman` находится готовая коллекция `CodeSlicer-Lab04.postman_collection.json`.

Импортируйте коллекцию в Postman и выполните запросы. Сначала рекомендуется выполнить POST, а затем GET, PUT и DELETE для созданной записи.

Данные сохраняются в файле `lab03-06/projects.json`. В отличие от ЛР3, изменения остаются после обновления страницы.

### 6. ЛР №5 — XMLHttpRequest и CORS

Для этой лабораторной нужно запустить **два сервера на разных портах**.

Первый сервер — Node.js API — должен работать на порту `8001`.

Откройте второе окно PowerShell, перейдите в папку `lab03-06` и выполните:

```powershell
python -m http.server 5500 --bind 127.0.0.1
```

Если команда `python` недоступна, попробуйте `py` вместо `python`.

Откройте:

http://127.0.0.1:5500/lab05/

Браузерный интерфейс будет отправлять запросы через `XMLHttpRequest` на сервер с портом `8001`.

При стандартных настройках запросы блокируются политикой CORS. Ошибку можно посмотреть в инструментах разработчика браузера (**F12 → Console**).

Для разрешения запросов:

1. Остановите Node.js-сервер сочетанием `Ctrl+C`.
2. В его окне PowerShell выполните:

```powershell
$env:ENABLE_CORS='1'
npm start
```

3. Обновите страницу ЛР5.

Теперь приложение сможет получать проекты через HTTP API. На странице можно искать проекты и открывать формы добавления и редактирования. В ЛР5 сохранение изменений ещё не реализовано.

### 7. ЛР №6 — Fetch API и сборка приложения

Для запуска ЛР6 верните сервер в обычный режим без CORS-настроек.

Остановите его через `Ctrl+C` и выполните:

```powershell
Remove-Item Env:ENABLE_CORS -ErrorAction SilentlyContinue
npm run build
npm start
```

Откройте:

http://127.0.0.1:8001/

Здесь можно:

- просматривать и искать проекты;
- создавать новые записи;
- редактировать существующие проекты;
- сохранять изменения;
- удалять проекты.

Взаимодействие с API реализовано через `fetch`, `Promise` и `async/await`.

Frontend и backend работают на одном адресе и порту. JavaScript собирается в `lab06/dist/bundle.js`.

Для просмотра запросов откройте **F12 → Network**, а для просмотра загруженного JavaScript — **F12 → Sources**.
