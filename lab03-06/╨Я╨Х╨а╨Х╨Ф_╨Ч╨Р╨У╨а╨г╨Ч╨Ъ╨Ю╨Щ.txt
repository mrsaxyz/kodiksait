ПОДГОТОВЛЕНО ДЛЯ РЕПОЗИТОРИЯ mrsaxyz/kodiksait

1. Распакуйте архив в C:\Users\sanch\Documents\kodiksait (внутри должны появиться README.md и папка lab03-06).
2. В PowerShell:
   cd "$HOME\Documents\kodiksait"
   git status
   git add README.md lab03-06
   git commit -m "Add CodeSlicer learning module for labs 3-6"
   git push origin main

3. Запуск и тестирование:
   cd lab03-06
   npm run build
   npm test
   npm start

4. По официальной методичке КАЖДОЙ лабораторной нужна собственная Git-ветка.
   Для ЛР5 и ЛР6 исходники frontend должны быть отделены от Node API.
   Дополнительные ветки можно создать после загрузки в main — это отдельный шаг.

5. НЕ УТВЕРЖДАЙТЕ преподавателю, что этот учебный модуль является
   копией или исходниками оригинального проекта CodeSlicer.

6. По предметной области нужно проверить индивидуальный вариант: методичка
   требует явно выделять «услуги» и «заявки», а здесь пока каталог проектов.

7. В PDF отчёта изображения экранов иллюстративные; настоящие скриншоты
   нужно снять в локально запущенном браузере перед защитой.
