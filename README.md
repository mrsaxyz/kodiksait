## Лабораторные работы №1–2

### Kodik Calculator

Веб-приложение для выполнения арифметических вычислений.

**Основные возможности:**

- Сложение, вычитание, умножение и деление.
- Перевод байтов в биты.
- История вычислений.
- Управление с клавиатуры.
- Очистка результата и удаление символов.

**Используемые технологии:** HTML5, CSS3, JavaScript.

### Как запустить

1. Скачайте репозиторий или откройте его на компьютере.
2. Перейдите в папку `lab01-02`.
3. Откройте файл `index.html` в браузере.

Установка дополнительных библиотек и запуск сервера не требуются.

**Отчёт:** `lab01-02/Отчет_Лабы1&2_Сигорский.pdf`.

## Лабораторные работы №3–6

### CodeSlicer — система анализа программного кода

CodeSlicer — локальное приложение для исследования структуры программных проектов, анализа зависимостей и оценки влияния изменений в исходном коде.

Система позволяет изучать взаимосвязи между файлами, функциями, модулями и другими компонентами программного обеспечения.

### Основные возможности

- **Анализ исходного кода.** Исследование структуры проектов и определение зависимостей между компонентами.
- **Визуализация графа.** Интерактивное представление связей между элементами программы.
- **Анализ изменений.** Определение компонентов, которые потенциально затрагиваются изменениями кода.
- **Веб-интерфейс.** Работа с системой через браузер.
- **Локальный HTTP API.** Обмен данными между клиентской и серверной частями.
- **Расширение VS Code.** Дополнительные инструменты анализа непосредственно в редакторе.
- **Автоматическое тестирование.** Проверка отдельных компонентов системы.

### Используемые технологии

| Компонент | Технологии |
|---|---|
| Веб-интерфейс | HTML, CSS, JavaScript |
| HTTP-запросы | Fetch API, JSON |
| Серверная часть | Python |
| API | Локальный HTTP-сервер |
| Анализ исходного кода | Python, Tree-sitter |
| Расширение VS Code | TypeScript, Node.js |
| Автоматическое тестирование | Pytest |
| Контроль версий | Git, GitHub |

### Установка на Windows

Для запуска необходимы:

- Python версии 3.10 или новее.
- Git для скачивания репозитория.
- Подключение к интернету для первоначальной установки зависимостей.

**Шаг 1. Скачайте репозиторий.**

Откройте PowerShell и выполните:

```powershell
git clone https://github.com/mrsaxyz/kodiksait.git
cd kodiksait
```

**Шаг 2. Перейдите в папку CodeSlicer.**

```powershell
cd lab03-06
```

**Шаг 3. Создайте виртуальное окружение Python.**

```powershell
py -3 -m venv .venv
```

**Шаг 4. Установите приложение и необходимые зависимости.**

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
```

После завершения установки приложение будет готово к запуску.

### Запуск CodeSlicer

Находясь в папке `lab03-06`, выполните:

```powershell
.\.venv\Scripts\python.exe -m impact_engine.local_api --host 127.0.0.1 --port 8001 --default-project .
```

После запуска откройте в браузере:

**http://127.0.0.1:8001/**

Для проверки работы сервера можно открыть:

http://127.0.0.1:8001/api/health

Веб-интерфейс получает данные от локального API. Результаты анализа формируются при работе с выбранным проектом.

### Проверка установки

В отдельном окне PowerShell, находясь в папке `lab03-06`, выполните:

```powershell
.\.venv\Scripts\codeslicer.exe doctor
```

Эта команда запускает диагностику установленного CodeSlicer.

### Как пользоваться приложением

1. Запустите локальный сервер.
2. Откройте веб-интерфейс в браузере.
3. Выберите или укажите проект для анализа.
4. Запустите построение графа зависимостей.
5. Изучите полученную визуализацию и информацию о компонентах.
6. Используйте инструменты анализа для исследования структуры проекта и влияния изменений.

Результаты анализа сохраняются локально. Для основного графа используется служебная папка `.impact_engine/`, создаваемая в анализируемом проекте.

### Структура CodeSlicer

| Путь | Назначение |
|---|---|
| `lab03-06/frontend/` | Веб-интерфейс приложения |
| `lab03-06/src/impact_engine/` | Основная логика анализа и HTTP API |
| `lab03-06/extensions/vscode/` | Расширение для Visual Studio Code |
| `lab03-06/plugins/` | Подключаемые адаптеры и компоненты |
| `lab03-06/support_packs/` | Правила анализа различных технологий |
| `lab03-06/scripts/` | Скрипты установки и проверки |
| `lab03-06/tests/` | Автоматические тесты |
| `lab03-06/docs/` | Техническая документация |
| `lab03-06/pyproject.toml` | Конфигурация Python-проекта и зависимости |

### Особенности проекта

CodeSlicer представляет собой единое приложение, а не четыре независимых программы для лабораторных работ №3, №4, №5 и №6.

В отличие от лабораторных №1–2, для работы основной части CodeSlicer необходим локальный сервер. Сам веб-интерфейс не требует отдельной установки Node.js: его обслуживает Python-приложение.

Папки виртуального окружения, кэша и локальных результатов анализа не включаются в репозиторий, поскольку они создаются автоматически при установке и использовании программы.

### Завершение работы

Чтобы остановить локальный сервер, вернитесь в окно PowerShell, где он запущен, и нажмите `Ctrl+C`.
