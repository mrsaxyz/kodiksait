## О репозитории

В репозитории представлены лабораторные работы №1–6 по дисциплине «Разработка интернет-приложений».

Работы объединены в два проекта, на примере которых рассматриваются основные этапы веб-разработки: создание интерфейса, программирование пользовательской логики, разработка серверной части и организация обмена данными.

- **ЛР №1–2 — Kodik Calculator:** веб-калькулятор на HTML, CSS и JavaScript.
- **ЛР №3–6 — CodeSlicer:** приложение для анализа программного кода, визуализации зависимостей и оценки влияния изменений.

## Содержание лабораторных работ

| Лабораторная | Содержание |
|---|---|
| **№1 — HTML** | Разработка структуры веб-калькулятора: элементы страницы, кнопки, поля отображения и организация интерфейса. |
| **№2 — CSS и JavaScript** | Оформление калькулятора, реализация вычислений, истории операций и обработки действий пользователя. |
| **№3 — Клиентская часть** | Веб-интерфейс CodeSlicer: навигация, работа с DOM, обработка событий и визуализация данных. |
| **№4 — Серверная часть** | Локальный HTTP-сервер CodeSlicer на Python, обработка GET/POST-запросов и формирование JSON-ответов. |
| **№5 — Клиент-серверное взаимодействие** | Обмен данными между JavaScript-интерфейсом и серверным API, отправка запросов и обработка ошибок. |
| **№6 — Асинхронные запросы** | Использование Fetch API, Promise и async/await для загрузки данных без перезагрузки страницы. |

## Проекты

### 1. Kodik Calculator — ЛР №1–2

Веб-калькулятор, выполненный в стилистике интерфейса среды разработки Kodik.

Приложение поддерживает арифметические операции, историю вычислений, ввод с клавиатуры и преобразование единиц информации.

Проект демонстрирует создание самостоятельного браузерного приложения средствами HTML, CSS и JavaScript.

**Расположение:** [`lab01-02/`](lab01-02/)

**Запуск:** открыть `lab01-02/index.html` в браузере.

### 2. CodeSlicer — ЛР №3–6

CodeSlicer — локальная система для исследования структуры программных проектов и связей между их компонентами.

Приложение позволяет строить интерактивные графы зависимостей, исследовать функции и модули, а также определять, какие части программы могут быть затронуты изменениями.

В рамках лабораторных работ рассматриваются четыре взаимосвязанные части приложения:

- **Интерфейс:** HTML, CSS, JavaScript.
- **Сервер:** Python и локальный HTTP API.
- **Обмен данными:** HTTP, JSON, Fetch API.
- **Асинхронная логика:** Promise, async/await и динамическое обновление интерфейса.

Дополнительно в проекте предусмотрены расширение для Visual Studio Code и автоматизированные тесты.

**Расположение:** [`lab03-06/`](lab03-06/)

Инструкция по установке и запуску находится в [`lab03-06/README.md`](lab03-06/README.md).
